⚠️ Deportick bloqueó las solicitudes

Deportick detectó que la consulta viene de un servidor externo y la bloqueó (error 403). Podés usar el script de Python de abajo, que corre en tu propia computadora y envía notificaciones de escritorio.

1. Instalá la dependencia (una sola vez):

pip install requests plyer

2. Guardá este archivo como checker.py y ejecutalo:

import time, requests
from plyer import notification

URL      = "https://www.deportick.com/event/riverplatefinalapertura26"
SOLDOUT  = "AGOTADO"        # texto que aparece cuando NO hay entradas
INTERVAL = 60               # segundos entre chequeos

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                  "AppleWebKit/537.36 (KHTML, like Gecko) "
                  "Chrome/124.0 Safari/537.36",
    "Accept-Language": "es-AR,es;q=0.9",
}

def check():
    try:
        r = requests.get(URL, headers=HEADERS, timeout=15)
        html = r.text.upper()
        if SOLDOUT.upper() not in html:
            return True, "AGOTADO no encontrado — puede haber entradas!"
        return False, "Sin entradas (AGOTADO encontrado)"
    except Exception as e:
        return None, f"Error: {e}"

print(f"Chequeando cada {INTERVAL}s → {URL}")
checks = 0
while True:
    ok, msg = check()
    checks += 1
    ts = time.strftime("%H:%M:%S")
    print(f"[{ts}] #{checks} — {msg}")

    if ok:
        print("🎉 ¡ENTRADAS DISPONIBLES! Abriendo el navegador...")
        notification.notify(
            title="🎟️ ¡Entradas disponibles!",
            message=msg,
            timeout=30
        )
        import webbrowser
        webbrowser.open(URL)
        break

    time.sleep(INTERVAL)

Ejecutá con: python checker.py
